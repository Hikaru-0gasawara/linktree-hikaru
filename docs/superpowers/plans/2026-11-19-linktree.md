# Linktree Business Card Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A one-screen, three-language static business-card page for Hikaru Ogasawara, reached by NFC/QR.

**Architecture:** Plain static files in `site/` (HTML, one CSS, two ES modules), served by Cloudflare Workers static assets. `site/i18n.js` is pure data + pure functions (unit-tested with `node --test`); `site/app.js` wires it to the DOM.

**Tech Stack:** HTML, CSS, vanilla JS ES modules, Node ≥22 built-in test runner, Wrangler for deploy. No dependencies.

**Spec:** `docs/superpowers/specs/2026-11-19-linktree-design.md` (read it first; it has the content, tokens, motion table and mobile rules). Visual reference: `.superpowers/brainstorm/1610-1795110247/content/final-v7.html`.

## Global Constraints

- No runtime/CDN dependencies; fonts and image self-hosted under `site/`.
- Colors only from the spec's token table, defined once as CSS custom properties on `:root`.
- Gold `#D8B24A` is used for: Play button, HUD brackets, panel labels, active language, résumé marker, focus ring. Nothing else.
- Square corners everywhere except the photo circle and dots.
- Never `user-scalable=no` / `maximum-scale`.
- All hover rules inside `@media (hover: hover) and (pointer: fine)`.
- Total page weight < 300 KB.
- Links: E-mail `mailto:hogasawara2311@outlook.com`; LinkedIn `https://www.linkedin.com/in/hikaru-ogasawara`; GitHub `https://github.com/Hikaru-0gasawara`; Play `https://hikaru-portfolio.okaru01.workers.dev/`; Résumé `https://hikaru-portfolio.okaru01.workers.dev/resume/hikaru-{pt|en|ja}.pdf`.
- Site URL constant `https://hikaru-card.okaru01.workers.dev/`.

## Review Focus

- 360×640 phone with JA selected: name on two lines without breaking a word, no horizontal scroll, everything visible without scrolling. (Task 2 browser check.)
- `localStorage` throws (private mode): page still loads and switches language. (Task 1 test `loadLang survives throwing storage`.)
- Browser language `ja-JP`, `en-GB`, `fr-FR`, empty list → JA, EN, PT, PT. (Task 1 test.)
- Birth date empty or the day before the birthday → fallback 21 / correct age. (Task 1 tests.)
- Reduced motion on: no movement, page fully visible immediately. (Task 3 check.)
